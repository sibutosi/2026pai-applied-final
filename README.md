# 最終課題：CRANE+ V2 独自モーション制御プログラム

## 1. 概要
CRANE+ V2 の各関節およびエンドエフェクタ（グリッパー）を連動させ、オーケストラの指揮者によるダイナミックな「4拍子タクト動作（四拍子指揮）」を再現したROS 2制御プログラムです。

本リポジトリでは、動作表現力と制御応答性の違いを検証するため、**標準テンポ版**と**高速テンポ版**の2種類のプログラムを収録しています。

---

## 2. 収録プログラムと特徴

| プログラム名 | 特徴・検証目的 | 想定テンポ |
| :--- | :--- | :--- |
| **`four-beat rhythm`** | **表現力・可動域重視（標準版）**<br>大きなストロークと手首の明確なスナップ、グリッパー連動による音楽的ダイナミクスを再現。 | 低速〜中速<br>（約60〜72 BPM） |
| **`four-beat rhythm more speed`** | **追従性・俊敏性検証（高速版）**<br>各ウェイポイントの到達時間を短縮し、慣性力によるブレを抑えつつ高速に切り返す応答性を検証。 | 中速〜高速<br>（約100〜120 BPM） |

---

## 3. 動作の工夫点・技術的特徴

- **直線的メリハリ軌道（折れ線補間による点打ち）**
  - 単純な正弦波（円運動）ではなく、指揮法に則り「1拍目の垂直急降下・沈み込み」と「リバウンド（跳ね上げ）」を実装。
  - 2拍目（左下への切り込みから左上への振り上げ）、3拍目（全空間を横断する大スイング）、4拍目（頂点へのすくい上げ）を明確に分離。
- **可動限界ストロークと手首のスナップ（イクタス）**
  - アームの可動域限界（旋回 ±1.4 rad、上下沈み込み）をフルに活用。
  - 各拍の打点（イクタス）で手首関節（Joint 4）を急激にスナップさせ、明確なビートの「点」を表現。
- **グリッパー（音の強弱表現）の連動**
  - アーム関節軌道（`/crane_plus_arm_controller/joint_trajectory`）とグリッパー（`/crane_plus_gripper_controller/joint_trajectory`）を完全同期。
  - 1拍目の強拍（フォルテ）で全開、2拍目の弱音（ピアノ）で閉じるなど、指揮者の手の表現を模したダイナミクス制御を実装。

---

## 4. 動作環境・前提
- **OS**: Ubuntu 22.04 LTS
- **ROS 2**: Humble
- **シミュレータ**: Gazebo (`crane_plus_gazebo`)
- **使用制御トピック**:
  - `/crane_plus_arm_controller/joint_trajectory`（5軸アーム制御）
  - `/crane_plus_gripper_controller/joint_trajectory`（グリッパー制御）
