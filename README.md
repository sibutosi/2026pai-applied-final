# 最終課題レポート：CRANE+ V2 独自モーション制御

## 1. 動作コンセプト

本課題では、CRANE+ V2（4軸アーム＋1軸ハンド）を用いた自律モーションとして、「オーケストラの指揮者（Conductor）によるダイナミックな4拍子タクト」を実装した。
ロボットの物理的可動域を限界まで活用し、単なる滑らかな円運動ではなく、人間の指揮法に則った「振り下ろし（点打ち）」「跳ね上げ（リバウンド）」「音楽的強弱（ダイナミクス）」を再現することを目的とした。

---

## 2. 実装の工夫点および技術的特徴

### ① 区分補間（折れ線軌道）による明確な拍（イクタス）の表現

三角関数による連続的な回転動作では動作のメリハリが失われるため、1小節（3.8秒）を4つの拍に明確に区分し、それぞれ直線的かつダイナミックに折り返す軌道を設計した。

* **1拍目（下・強拍/フォルテ）**：直立上空からテーブル直前までアーム全体を一気に沈み込ませ（最深点打ち）、反動で中央やや上へリバウンドする。
* **2拍目（左・弱音/ピアノ）**：左端限界（約 -80°）の低空へ切り込み、そこから左上空高くへ大きくタクトを振り上げる。
* **3拍目（右・中強/メゾフォルテ）**：左上空から右端限界（約 +80°）まで全空間を横断して薙ぎ払い、低空で点を打ってから右上へ跳ね上げる。
* **4拍目（上・弱）**：右から中央最頂点へタクトを天高く突き上げ、次の1拍目への呼吸・予備動作（アウフタクト）をとる。

### ② ロボットの物理可動限界を活用したダイナミクス

* **旋回（Joint 1）**：可動限界付近の $\pm 1.4\ \text{rad}$（約 $\pm 80^\circ$）まで展開し、オーケストラ全体を見渡す特大ストロークを実現。
* **上下・沈み込み（Joint 2 & 3）**：Joint 2 を $-1.1\ \text{rad}$（前傾限界）まで倒し込み、肘（Joint 3）を $1.45\ \text{rad}$ まで曲げることで、深々とした叩き落としを表現。
* **手首の点打ち（Joint 4）**：各拍の頭で手首を $-1.3\ \text{rad}$ まで急激にスナップさせ、指揮棒の先端がピシッと止まる「点」を強調。

### ③ エンドエフェクタ（グリッパー）の音楽的連動

アームの軌道だけでなく、音楽表現の一環としてハンド開閉を統合制御した。

* 1拍目のフォルテ（強打）ではグリッパーを全開（$-0.5236\ \text{rad}$）にして強い指示を表現。
* 2拍目のピアノ（弱音）ではグリッパーを完全に閉じ（$+0.1745\ \text{rad}$）、繊細な指示を表現。

### ④ ROS 2 control 規格への適合

`teleop_keyboard.py` の構造を踏襲し、アーム系（`/crane_plus_arm_controller/joint_trajectory`）とグリッパー系（`/crane_plus_gripper_controller/joint_trajectory`）の2つのコントローラーに分離してパブリッシュする構成とした。また、実機・シミュレータの関節定義に合わせて `[joint1, joint2, joint4, joint3]` の順序で指令値を送信している。

## 3. システム構成・実行環境

* **OS / ミドルウェア**: Ubuntu / ROS 2
* **シミュレータ**: Gazebo (`crane_plus_gazebo`)
* **制御周期**: 33Hz（タイマー周期 0.03秒）
* **送信トピック**:
* `/crane_plus_arm_controller/joint_trajectory` (`trajectory_msgs/msg/JointTrajectory`)
* `/crane_plus_gripper_controller/joint_trajectory` (`trajectory_msgs/msg/JointTrajectory`)

## 4. 実行手順

### ターミナル 1（Gazebo 環境の起動）

```bash
ros2 launch crane_plus_gazebo crane_plus_with_table.launch.py

```

### ターミナル 2（制御プログラムの実行）

```bash
cd ~/pai_ws
source install/setup.bash
python3 unique_dance.py

```

## 5. 課題の振り返り・まとめ

初期の実装ではトピック構成の不一致や三角関数の丸まりによる「単なる旋回動作」になっていたが、手動テレオペレーションの構造解析と指揮法の動作分析を通じて、各関節の可動限界を活用したメリハリのある軌道生成を完成させた。多自由度アームとエンドエフェクタの連動制御、およびROS 2 controlによる軌道指令の基礎を深く理解することができた。
