# 最終課題：CRANE+ V2 独自モーション制御プログラム

## 1. 概要
CRANE+ V2 の各関節およびエンドエフェクタ（グリッパー）を連動させ、オーケストラの指揮者によるダイナミックな「4拍子タクト」を再現した制御プログラムです。

## 2. 動作の工夫点・技術的特徴
- **直線的メリハリ軌道（折れ線補間）**
  - 単純な正弦波（円運動）ではなく、指揮法に則り「1拍目の垂直急降下・沈み込み」と「リバウンド（跳ね上げ）」を実装。
  - 2拍目（左下への切り込みから左上への振り上げ）、3拍目（全空間を横断する大スイング）、4拍目（頂点へのすくい上げ）を明確に分離。
- **可動限界ストロークと手首の点打ち（イクタス）**
  - アームの可動域限界（旋回 ±1.4 rad、上下沈み込み）をフルに活用。
  - 各拍の頭で手首関節（Joint 4）を急激にスナップさせ、明確なビートの「点」を表現。
- **グリッパー（表現力）の連動**
  - 1拍目の強拍（フォルテ）で全開、2拍目の弱音（ピアノ）で閉じるなど、音楽的な強弱（ダイナミクス）と連動した開閉制御を実装。

## 3. 動作環境・前提
- ROS 2
- Gazebo (`crane_plus_gazebo`)
- 制御トピック：
  - `/crane_plus_arm_controller/joint_trajectory`
  - `/crane_plus_gripper_controller/joint_trajectory`
